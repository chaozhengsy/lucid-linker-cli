# lucid-linker-cli

DevOps engineer · Ansible and Terraform

给自己省点事的小工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/lucid-linker-cli.git
cd lucid-linker-cli
cargo build --release
```
